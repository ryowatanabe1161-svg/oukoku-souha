# 王国争覇 〜ふーさんたちの デッキ構築バトル〜

ブラウザで遊べる、2〜4人用のデッキ構築カードゲーム（オンライン対戦／CPU とひとりで）。
Donald X. Vaccarino 作のデッキ構築ゲームを参考にした **非公式ファンメイド** です。
カードの名前・文章・絵・音はすべてオリジナル。実装したルールと裁定は [RULES.md](RULES.md)。

**ふらっとgames**　制作 watg

## 遊びかた

- `index.html` を開くだけ（静的ファイルのみ。GitHub Pages で動きます）。
- 「CPUと ひとりで遊ぶ」：空いた席に CPU（ふーさん🐻・ミミ🐰・ロボミ🤖・ニャコ😺・ポチ太🐶・コンタ🦊）。強さは 弱い／普通／強い／アストラウルトラ😎。
- 「部屋を作る」：部屋コード・招待URL・QRコードで友だちを呼べます（PeerJS による P2P、STUN のみ）。途中で切れても同じニックネームで元の席に戻れ、ホストはリロードしても「再開」できます。
- 王国（10種類）は「おすすめ」「ランダム」「自分で選ぶ」から。10種のカード（宿場町・鉄打ち場・錬金室・謝肉祭・バザール・円卓の間・呪術師・自警団・謁見の間・両替商）は独自の効果にしてあります。

## しくみ

| ファイル | 内容 |
|---|---|
| `cards.js` | カードのデータ（独自の名前・絵文字・説明） |
| `logic.js` | ルールエンジン。ゲーム全体を1つのジェネレーターで進め、判断が必要なところで止まる。乱数は状態の中（seed）なので「seed＋判断の列」で完全に再現できる。`viewFor` は見てよい情報だけを返す |
| `ai.js`・`weights.js` | CPU。公開情報だけで判断（`know()`）。強い＝王国を見て作戦（お金＋X、宿場町＋ドロー、呪術師対策、伯爵領の時期、最後から2枚目の王冠領ルール、山切れの判断）。アストラウルトラ＝開始時に候補の作戦どうしを数百回自己対戦させて一番勝てるものを選ぶ（覚醒の演出の間に少しずつ計算） |
| `host.js`・`net.js` | ホストが唯一の正（authoritative）。参加者には自分が見てよい情報だけを送る |
| `ui.js`・`app.js`・`index.html` | 画面。スマホ縦（375px〜）は縦レイアウト、スマホ横・PCは横画面のゲーム盤（風景の背景・扇形の手札・上にスワイプで使う） |
| `art.js` | カードの絵（CSSで描いた場面＋絵文字。すべてオリジナル） |
| `fx.js`・`audio.js`・`bgm.js`・`chars.js` | 演出・効果音・BGM（Web Audio で合成）・キャラのセリフ |

## テスト

```
node test/logic.test.js          # 全カード・謁見の間の組み合わせ・跳ね橋・シャッフル・終了・同点・情報もれ・CPUの公平さ（475項目）
node test/sim.js                  # CPU の勝率（並列）→ test/sim-report.json
node test/stun.js <ip> 3478 &  python3 -m http.server 18791 --bind 127.0.0.1 &  node test/e2e.js <ip> 18791
```
